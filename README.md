# hexipy
turns any string into hex format using python `hex()` built-in function

===================================================================================================================
                                                how to use:
It is very easy to as you just enter what need to do and it'll show a hex-formatted version of that string

===================================================================================================================
                                              how to exit
as easy as ever. just hit ctrl-c and you're out and about
